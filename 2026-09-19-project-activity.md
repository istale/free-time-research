- **3W1H：**
  - **What：** C++ header-only / compiled library（`include/fmt/` 為 0-dep header path + `src/` 為加速函式）；核心 API `fmt::format("Hello, {}!", name)` ≈ Python f-string；C++20 標準化後成 std library reference implementation（`std::format` 的 upstream testbed）；支援 chrono、ranges、printf-compat、Unicode、user-defined-type formatting ext point。
  - **Why：** C++ 寫 string formatting 用 `printf("%d", x)` 是 type-unsafe + locale-fragile、用 `std::ostringstream` 是 verbose + 慢、`std::to_string` 是無 format control —— 三者都不堪用。fmt 同時解三個痛點：(1) **Python-style syntax 可讀**、(2) **type-safe**、(3) **快 5-10× vs sprintf/iostream**（Dragonbox floating-point algorithm 是 fmt 招牌，已被 C++17 `to_chars` 抄走）。近期受關注原因：C++20/23 採納、oss-fuzz badge 浮現、CHRONO + ranges 一直擴（標準庫對齊）。
  - **Who：** C++ lib developer 想用 Python-style format 而不想引入 runtime 的（fmt core header-only）；Chromium / Abseil / LLDB / WebRTC 等大型 C++ codebase maintainer（內部已用 fmt、需要 format string 測試）；**AI coding agent（Claude Code / Codex / Cursor）對 C++ 時默認用 fmt**（無 agent lib text generator 也必生成的 stdlib 知識）。
  - **How：** 兩條路徑。(a) **Header-only inline：`git clone https://github.com/fmtlib/fmt` → `#include <fmt/format.h>` 即可用，0-dep header-only path**（無 CMake / link）。(b) **Compiled**：CMake `add_subdirectory(fmt)` 然後用 `fmt::fmt`。Try online：Compiler Explorer `godbolt.org/z/8Mx1EW73v` 直接瀏覽器試；Demoshell live demo 可用。
- **安裝方式：**
