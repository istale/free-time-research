- **3W1H：**
  - **What：** Python-based book-to-agent-skill converter — 兩半：deterministic Python **extractor**（document → clean text + metadata） + spec-driven **generator**（agent 跟 SKILL.md 轉成結構化 skill）；on-demand chapter files keep loaded skill small；遵循 [Agent Skills](https://github.com/agentskills/agentskills) open standard。
  - **Why：** 解決「買了好書、讀完一次、3 個月後忘光 / PDF 搜尋只回頁碼不回答 / agent 沒書就 hallucinate / 筆記 200 行從此不再看」的痛點。Book-to-skill 把書轉成 structured skill，agent on-demand load；發現「PDF-reading agent 每次都 re-fetch ToC + backtrack + re-process」的 discovery loop tax 是 2026 主導 insight — 透過一次性付 structuring cost（conversion），後續 query proportional to answer（**24×–51× 縮減**）。
  - **Who：** 想把技術書（CS / ML / domain reference）變成 Claude Code / Copilot CLI / Amp / Codex on-demand skill 的 developer；對「discovery loop tax」有量化需求的 RAG / context-engineering 研究者；想要 brand book / design system / RFC / compliance docs 變成 agent skill 的 enterprise team；對「on-demand chapter loading vs upfront summary」niche 有興趣的 harness engineer。
  - **How：** (a) **As agent skill**（推薦）：`npx skills add virgiliojr94/book-to-skill` 一行裝所有；或 per-host `git clone https://github.com/virgiliojr94/book-to-skill.git ~/.claude/skills/book-to-skill`（Claude Code）或 `~/.copilot/skills/book-to-skill`（Copilot CLI）或 `~/.agents/skills/book-to-skill`（Amp/cross-agent + Codex）。裝完跑 `/book-to-skill ~/path/to/your-book.pdf` 或 `/book-to-skill ~/path/to/your-book.epub`。(b) **As standalone CLI**：`pip install "book-to-skill[pdf,epub,docx] @ git+https://github.com/virgiliojr94/book-to-skill.git"` + `book-to-skill ~/path/to/book.pdf --mode text`。**Check setup**：`python3 scripts/extract.py --check` 一次列出所有 extractors 與對應 install command。
